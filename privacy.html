JR Spikeston Alerts: Privacy Policy

Last updated November 6, 2026.

JR Spikeston Alerts is a personal text message program run by James Spikeston, a sole proprietor. It sends health notifications (for example, that a new lab result or doctor message is available in a patient portal) from +1 817 567 8948 to a single phone number belonging to James Spikeston himself.

Information collected

The program stores only the recipient's mobile phone number and the delivery status of each message. It does not collect information from anyone else.

How information is used

The phone number is used only to send the alerts the recipient set up for himself. Messages are delivered through Twilio, which processes the number and message content solely to deliver them.

Sharing

No mobile information will be shared with third parties or affiliates for marketing or promotional purposes. All the above categories exclude text messaging originator opt-in data and consent; this information will not be shared with any third parties.

Opting out

Reply STOP to any message to stop receiving texts. Reply HELP for help. Message and data rates may apply.

Contact

Text HELP to +1 817 567 8948.
